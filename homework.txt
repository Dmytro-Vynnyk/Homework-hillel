1. 'number' + 3 + 3
'number' + 3 → "number3" (JavaScript бачить, що є рядок, і перетворює число 3 на рядок).
"number3" + 3 → "number33" (знову рядок + число → конкатенація)
Відповідь: 'number33'

2. null + 3
null в числовому контексті стає 0.
0 + 3 → 3.
Відповідь: 3

3. 5 && "qwerty"
Оператор && повертає останнє істинне значення, якщо всі значення істинні.
5 — true (істинне значення).
"qwerty" — теж true.
Останнє true значення — "qwerty"
Відповідь: "qwerty"

4. +'40' + +'2' + "hillel"
+'40' → 40 (унарний + перетворює рядок '40' у число 40).
+'2' → 2.
40 + 2 → 42.
42 + "hillel" → "42hillel" (конкатенація з рядком).
Відповідь: "42hillel"

5. '10' - 5 === 6
'10' - 5 → 10 - 5 → 5 (рядок '10' перетворюється в число).
 5 === 6 → false (оскільки 5 не дорівнює 6).
Відповідь: false

6. true + false
true → 1, false → 0.
1 + 0 = 1.
Відповідь: 1

7. '4px' - 3
'4px' не можна перетворити в число.
NaN - 3 = NaN.
Відповідь: NaN

8. '4' - 3
'4' → 4 (перетворення рядка в число).
 4 - 3 = 1.

9. '6' + 3 ** 0
3 ** 0 → 1 (оскільки будь-яке число в степені 0 дорівнює 1).
'6' + 1 → "61" (конкатенація).
Відповідь: "61"

10. 12 / '6'
'6' → 6.
12 / 6 = 2
Відповідь:2

11. '10' + (5 === 6)
 5 === 6 → false.
'10' + false → "10false" (конкатенація).
Відповідь: "10false"

12. null == ''
null дорівнює undefined, але не порожньому рядку.
null == '' → false
Відповідь: false

13. 3 ** (9 / 3)
9 / 3 → 3.
3 ** 3 → 27
Відповідь:27

14. !!'false' == !!'true'
'false' → truthy, 'true' → truthy.
!!'false' → true, !!'true' → true.
true == true → true.
Відповідь: true

15. 0 || '0' && 1
'0' && 1 → 1 (останнє truthy).
0 || 1 → 1 (перший truthy).
Відповідь: 1

16. (+null == false) < 1
+null → 0.
0 == false → true.
true < 1 → false (true → 1, а 1 < 1 → false).
Відповідь: false

17. false && true || true
false && true → false (бо false).
false || true → true.
Відповідь: true

18. false && (false || true)
(false || true) → true.
false && true → false.
Відповідь: false

19. (+null == false) < 1 ** 5
+null → 0.
0 == false → true.
1 ** 5 → 1.
true < 1 → false (true → 1, а 1 < 1 → false).
Відповідь: false
